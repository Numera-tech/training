# Trainingsplan

Persönliche Trainings-App (Push/Pull/Beine, 3× pro Woche) als einzelne Datei `index.html`.

- Läuft komplett im Browser, keine Server, kein Konto.
- Alle Eingaben (Gewichte, Wiederholungen, Notizen, Verlauf, Wochenplan) bleiben nur lokal auf dem Gerät gespeichert.
- Nutzung: über GitHub Pages öffnen, dann in Safari „Teilen → Zum Home-Bildschirm“.
- Sicherung: In der App unter Einstellungen → „Sicherung exportieren“.
